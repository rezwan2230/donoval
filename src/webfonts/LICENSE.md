## Font Mapping

The original Donovan Legal site used commercially licensed fonts. These have been replaced with visually equivalent open-source alternatives from Google Fonts:

| Original Font | Replacement | Similarity | File Pattern |
|--------------|-------------|------------|--------------|
| **Trajan Pro Bold** (Adobe) | **Cinzel Bold** (Natanael Gama) | Roman inscription style, near-identical uppercase forms | `TrajanPro-Bold.*` |
| **Gotham Light** (Hoefler & Co) | **Montserrat Light** (Julieta Ulanovsky) | Geometric sans-serif, 88% visual similarity | `Gotham-Light.*` |
| **Gotham Medium** (Hoefler & Co) | **Montserrat Medium** (Julieta Ulanovsky) | Same geometric DNA, matching proportions | `Gotham-Medium.*` |
| **Gotham Bold** (Hoefler & Co) | **Montserrat Bold** (Julieta Ulanovsky) | Same geometric DNA, matching proportions | `Gotham-Bold.*` |
| **Open Sans** (Google) | **Open Sans** (Steve Matteson) | Same font, self-hosted | `OpenSans-*.*` |

Files are named to match the original CSS `@font-face` declarations so the stylesheet works without modification.
