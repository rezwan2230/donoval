### Section Details

1. **Outer Wrapper** (`.big-screen`): 10px padding, minimum 930px height, full width. Establishes the outer page frame.

2. **Inner Border** (`.border-inside`): 1px solid `#ddd` border wrapping all content. Creates the inner page frame.

3. **Navigation Bar** (`.navbar.menubar`):
   - Flexbox, space-between alignment
   - Left: Logo image (`img/base-hover.png`, max-width 150px)
   - Right: Horizontal nav links (HOME, THE FIRM, THE PRACTICE, CLIENTS, CONTACT) in uppercase Gotham Medium
   - Mobile: Hamburger icon (hidden on desktop ≥992px), slides-in overlay nav
   - Bottom margin: 20px (`margin-bottom: 20px`)

4. **Main Content Area** (`.content-pa.keep-m`):
   - `margin-top: 150px` (`.keep-m` class)
   - Bootstrap 12-column grid with 2 columns:
     - **Left sidebar** (`col-lg-4`, `order-lg-1`): "PRACTICE AREAS" section with accordion
     - **Right content** (`col-lg-8`, `order-lg-2`): "EXPERIENCE" section with bullet list
   - Note: In HTML source, right column (col-lg-8) comes first, then left column (col-lg-4), but CSS `order` properties visually swap them on large screens (left sidebar appears first on desktop)

5. **Left Sidebar — Practice Areas**:
   - `h2.title-inside`: "PRACTICE" (Gotham Light) + "AREAS" (Gotham Bold, gold `#c1a221`), font-size 30px, letter-spacing 3px
   - Accordion (`#pa-accordion`): expandable sections separated by `<hr>` (1px solid `#ccc`)
   - Each section: link in gold (`#c1a221`) + `+` icon button
   - Links: REAL ESTATE, BUSINESS LAW, TAXATION, EXPERIENCE
   - Card/header background: white, no border

6. **Right Content — Experience**:
   - `h5.bold.yellow`: "EXPERIENCE" in bold, `#c1a221` gold, margin-bottom 30px
   - Introductory text paragraph: "Below is a sample of the legal services we offer our clients."
   - `ul.experience-list`: disc-style list, 10 bullet items in Open Sans, margin-bottom 15px per item

7. **Footer** (`.copy-inside`):
   - Centered, uppercase, Open Sans, 13px, letter-spacing 2px
   - Text: "© DONOVAN LEGAL PLLC. 2022. | DISCLAIMER"
   - margin-top: 180px, margin-bottom: 20px

### Column/Spacing Patterns
- Bootstrap container (max-width responsive)
- 2-column layout on desktop (lg breakpoint ≥992px): 33.33% / 66.67% split
- Single column stacked on mobile
- Horizontal rules (`hr`) as section dividers in sidebar (margin: 10px 0)
- Experience list items: `margin-bottom: 15px`
- Overall large top margin (150px) between nav and content
